# JASTAR HUB

**Одна молодёжь. Единые возможности. Общие результаты.**

Единая цифровая платформа Молодёжных советов группы АО «Самрук-Қазына», портфельных компаний Фонда и их дочерних организаций. Профили молодых сотрудников, проекты и мероприятия советов, независимая экспертиза и открытые рейтинги, в которых баллы начисляются только за подтверждённые результаты.

> **Демо-версия.** Все люди, показатели, оценки и рейтинги в прототипе вымышлены и помечены «ТЕСТ». Данные хранятся только в браузере пользователя (localStorage и IndexedDB). Схема рабочей базы данных — в `supabase/schema.sql`.

## Запуск

Откройте `index.html` в браузере — сервер и установка зависимостей не нужны.

Чтобы опубликовать через **GitHub Pages**: Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`. Сайт будет доступен по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Разделы

Главная (дашборд с картой регионов), компании и Молодёжные советы, участники, личный кабинет, проекты, календарь мероприятий, рейтинг советов, ТОП-100 молодых лидеров, кабинет независимого эксперта, новости и медиа, база знаний, аналитика для руководства (Excel и PDF, квартальный отчёт), сравнение компаний, администрирование, открытая методика рейтинга.

## Методика рейтинга (кратко)

**Молодёжные советы:** проекты и результативность 25%, охват и вовлечённость 20%, социальная деятельность 15%, профессиональное развитие 15%, межкорпоративное взаимодействие 10%, инновации 10%, информационная активность 5%.

**Молодые лидеры:** личный вклад в проекты 30%, организация и лидерство 20%, реализованные инициативы 20%, волонтёрство 10%, межкорпоративное взаимодействие 10%, профессиональное развитие и наставничество 10%.

- Учитываются только активности, подтверждённые независимым экспертом.
- Качество проекта = средняя оценка эксперта × (0,5 + 0,5 × выполнение KPI, не выше 120%).
- Нормирование по размеру: вовлечённость = 1 − e^(−охват / численность молодёжи); суммы по проектам делятся на √(численность / 100).
- Каждый показатель приводится к шкале 0–100 по лучшему результату периода.
- Личные баллы — только в пределах доли участника в команде (сумма долей = 100%).

Защита от завышения: проверка дублей, обязательные KPI и документ-доказательство, фото не влияют на баллы, подтверждённые значения не могут превышать заявленные, конфликт интересов экспертов, история рейтинга, апелляции, журнал аудита.

## Структура репозитория

```
index.html            собранное приложение (открывается напрямую)
build.py              сборка index.html из src/
src/
  01-data.js          справочники, оргструктура, генератор тестовых данных
  02-core.js          хранилище, роли (RBAC), расчёт рейтингов, проверка, аудит, API-слой
  03-ui.js            компоненты, графики, карта, маршрутизация, оболочка
  04-pages-a.js       главная, компании, участники, профили, вход и регистрация
  05-pages-b.js       проекты и мероприятия
  06-pages-c.js       рейтинги, экспертиза, новости, база знаний, аналитика, админка, методика
  07-main.js          обработчики событий и запуск
  styles.css          дизайн-токены и стили (светлая и тёмная темы, адаптивность)
supabase/schema.sql   схема PostgreSQL для Supabase: таблицы, RLS, триггеры, расчёт рейтинга
```

После изменения файлов в `src/` выполните `python3 build.py`.

## Переход к рабочей версии

Целевой стек: Next.js + TypeScript + Tailwind CSS, Supabase (PostgreSQL, Auth, Storage), Recharts.

1. Создать проект Supabase и выполнить `supabase/schema.sql`.
2. Создать бакеты Storage: `evidence` (приватный), `avatars` и `media` (публичные).
3. Заменить объект `api` в `src/02-core.js` и прямые изменения `DB` на вызовы Supabase — интерфейс слоя данных повторяет будущие запросы.
4. Перенести расчёт рейтинга в функцию БД `company_scores()` и Edge Function с кэшем.
5. Подключить корпоративный вход (SSO) и перевод интерфейса на казахский и английский (архитектура i18n уже заложена).
